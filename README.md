# 🤖 Pahna AI Chatbot (Lightweight WordPress AI Plugin)

یک مینی‌افزونه سبک و اختصاصی برای وردپرس جهت اتصال مستقیم به مدل‌های زبانی هوش مصنوعی (DeepSeek, LLaMA, OpenAI) بدون وابستگی به افزونه‌های سنگین و بدون مشکل فایروال سرورهای داخلی.

## ✨ ویژگی‌ها (Features)
- ⚡ **فوق‌العاده سبک:** پیاده‌سازی شده با جاوااسکریپت خالص (Vanilla JS) و REST API وردپرس بدون افت سرعت سایت.
- 🛡️ **سازگار با زیرساخت ایران:** حل مشکل خطاهای تحریم و 403 با سازگاری با پرووایدرهای OpenAI-compatible (مانند AvalAI).
- 🧠 **شخصی‌سازی شده:** دارای System Prompt بهینه‌سازی شده با ساختار Heredoc برای خدمات هاستینگ و پشتیبانی.
- 🔒 **امنیت بالا:** بدون لود اسکریپت‌های حجیم خارجی، اعتبارسنجی ورودی‌ها با توابع امنیتی وردپرس.

## 🚀 نحوه نصب و راه‌اندازی (Installation)
1. پوشه افزونه را در مسیر `wp-content/plugins/` قرار دهید.
2. افزونه **Pahna AI Chatbot** را در پیشخوان وردپرس فعال کنید.
3. در فایل افزونه، مقدار `PAHNA_AI_KEY` را با کلید API خود جایگزین کنید (یا در `wp-config.php` ست کنید):
```php
define('PAHNA_AI_KEY', 'aa-your-api-key');
